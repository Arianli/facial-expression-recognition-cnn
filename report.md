# Research Report: Facial Expression Recognition with CNN

## 1. Introduction

This project explores facial expression recognition using convolutional neural networks. Facial expression recognition is a computer vision task that aims to classify facial images into emotion categories such as happy, sad, angry, and neutral.

## 2. Research Motivation

This project is motivated by my previous research experience with HKUST CSE, where I worked on deep learning-based emotion classification. Through this project, I aim to build a complete research-style pipeline from data preprocessing to model evaluation.

## 3. Method

The planned method is to train a CNN model on facial expression images. The model will learn visual features from facial images and classify them into seven emotion categories.

## 4. Evaluation Plan

The model will be evaluated using:

- Accuracy
- Training and validation loss
- Confusion matrix
- Per-class classification performance

## 5. Future Work

Future improvements may include transfer learning, data augmentation, and comparison with more advanced architectures.
